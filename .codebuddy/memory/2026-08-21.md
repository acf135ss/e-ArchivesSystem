## 修复：登录失败 + 数据库初始化模块（同日下午）

用户反馈 admin/admin123 登录失败。排查确认两个根因并已修复：

1. **密码哈希崩溃（根因）**：`passlib 1.7.4` 与已安装 `bcrypt 4.x+` 不兼容，`hash_password` 抛 `AttributeError`/`ValueError`，导致初始化管理员账号失败、登录失败。
   - 修复：`core/security.py` 改为直接使用 `bcrypt` 库（hashpw/checkpw，超 72 字节截断）；`requirements.txt` 移除 `passlib[bcrypt]`。
   - 已验证 `hash_password`/`verify_password` 正常。

2. **数据库初始化缺失**：原 `init_db.py` 仅 `create_all` 建表，不创建数据库本身，且需手动改配置。
   - 修复：重写 `app/db/init_db.py` 为**交互式初始化模块**：交互式输入 MySQL 主机/端口/用户名/密码/库名/管理员账号密码 → 自动 `CREATE DATABASE IF NOT EXISTS`（utf8mb4）→ `create_all` 建表 → 初始化默认分类 + 管理员 → 可选写入 `backend/.env`（用 `quote_plus` 编码密码）。支持命令行参数非交互式。

3. 登录页背景色：`#667eea→#764ba2` 紫色渐变改为灰白 `#f7f8fa→#eef0f3`，卡片加浅阴影。

已更新 `README.md` 与 `docs/开发进度记录.md` 的初始化说明。
