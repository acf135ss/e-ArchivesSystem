## 1. 项目概述

### 1.1 项目背景

建设一套电子档案系统，用于集中记录和管理个人及组织的各类证件、证书与经历证明材料，实现档案的电子化存储、便捷查询、分类管理与到期提醒，替代传统的纸质/散乱存放方式。

### 1.2 项目目标

1. 对各类证件、证书、经历证明进行电子化归档与统一管理。
2. 提供便捷的分类、搜索、筛选与统计能力，快速定位所需档案。
3. 对有有效期的证书提供到期提醒，避免证件失效带来的风险。
4. 支持附件扫描件上传存储，保证证明材料完整留存。
5. 多人使用、账号隔离，管理员统一管理账号与数据。

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| 档案 | 一条被管理的记录，对应一份证件/证书/经历证明 |
| 分类 | 档案的类型归属（证件类 / 获奖证书类 / 经历证明类等） |
| 附件 | 证书的电子扫描件（图片或 PDF） |
| 到期提醒 | 对有有效期档案的临期/过期提示 |

## 2. 用户与角色

系统为 Web 多人系统，采用账号隔离机制。

| 角色 | 权限说明 |
|------|----------|
| 普通用户 | 仅能查看、管理**自己**的档案；可新增、编辑、删除、上传附件；接收自己的到期提醒 |
| 管理员 | 账号管理（创建/停用/重置密码）；数据管理（可查看全部档案）；分类管理（自定义分类） |

> 权限模型：**仅个人私有**。普通用户数据互相隔离，管理员拥有全局查看与数据管理权限。

## 3. 档案分类体系

### 3.1 默认三大分类

| 一级分类 | 说明 | 典型档案示例 |
|----------|------|--------------|
| 证件类 | 个人身份与学历相关证件 | 身份证、毕业证、学位证 |
| 获奖证书类 | 各类荣誉与考试成绩证书 | 比赛获奖、评优、四六级、奖学金 |
| 经历证明类 | 工作与实习经历证明 | 工作成果证明、实习证明 |

### 3.2 分类扩展

- 支持管理员**自定义新增分类**，分类不限于默认三大类。
- 分类需具备：分类名称、说明、是否启用、排序。
- 分类支持增、删、改，删除前需校验该分类下无关联档案（或提供迁移处理）。

## 4. 功能需求

### 4.1 档案管理（核心 CRUD）

**新增档案**：用户填写档案信息并可选上传附件。

**编辑档案**：用户可修改自己档案的任意字段，重新上传/替换/删除附件。

**删除档案**：删除自己的档案，需二次确认；删除为逻辑删除或物理删除（待技术方案确定）。

**查看档案**：详情页展示完整字段与附件预览（图片在线预览、PDF 下载/预览）。

### 4.2 档案字段定义（完整元数据）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 档案名称 | 文本 | 是 | 如「大学英语六级证书」 |
| 档案分类 | 枚举/外键 | 是 | 关联分类体系 |
| 颁发机构 | 文本 | 否 | 如「教育部考试中心」 |
| 颁发日期 | 日期 | 否 | 证书颁发时间 |
| 有效期至 | 日期 | 否 | 有有效期则填写，用于到期提醒 |
| 证书编号 | 文本 | 否 | 证书唯一编号 |
| 等级/成绩 | 文本 | 否 | 如四六级分数、奖学金等级、比赛奖项等级 |
| 持有人 | 文本 | 否 | 默认当前用户，可修改 |
| 标签 | 多值 | 否 | 自定义标签，便于筛选 |
| 关联经历 | 文本/外键 | 否 | 关联的工作/实习经历描述 |
| 备注 | 长文本 | 否 | 补充说明 |
| 附件 | 文件 | 否 | 图片/PDF 扫描件，支持多附件 |

### 4.3 附件管理

- 支持上传图片（jpg/png 等）与 PDF。
- 存储方式：**本地磁盘存储**（服务器本地目录，适合小规模自部署）。
- 单条档案支持多个附件。
- 提供附件预览（图片在线预览、PDF 在线预览/下载）。
- 附件需做大小限制与格式校验（具体值在技术方案中确定）。

### 4.4 搜索、筛选与统计

- **关键字搜索**：按档案名称、证书编号、颁发机构、备注等字段模糊搜索。
- **组合筛选**：按分类、标签、颁发日期区间、有效期区间筛选。
- **首页统计概览**：
  - 档案总数
  - 各分类档案数量分布
  - 即将到期档案数、已过期档案数

### 4.5 到期提醒

- 提醒范围：填写了「有效期至」的档案。
- 提醒规则：在有效期临近（如提前 30/60/90 天，可配置）时，进入「即将到期」列表；超过有效期进入「已过期」列表。
- 提醒方式：**站内提醒**（登录后首页显示即将到期/已过期档案列表与数量）。
- 邮件提醒为**后续迭代**，本期不实现。

### 4.6 导入导出

- **导出**：按当前筛选结果导出档案清单为 Excel。
- **导入**：支持按模板 Excel 批量导入档案信息。
- 导入需提供模板下载、格式校验与错误行提示。

### 4.7 操作日志

- 记录用户对档案的操作：谁、在何时、对哪条档案、做了什么（新增/修改/删除）。
- 管理员可查看操作日志；普通用户可查看自己档案的操作记录（视权限设计确定）。
- 日志用于追溯与审计。

### 4.8 账号管理（管理员）

- 创建用户账号、停用/启用账号、重置密码。
- 查看/管理所有用户档案。

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 技术架构 | Web 前后端分离（React/Vue + Node/Python 后端，具体选型在技术方案中确定） |
| 安全 | 登录鉴权、接口鉴权、账号数据隔离、附件访问权限控制 |
| 性能 | 常规查询响应 < 2s；附件上传/下载满足日常使用 |
| 可用性 | 界面简洁，操作流程清晰，关键操作有二次确认 |
| 兼容性 | 支持主流现代浏览器（Chrome/Edge 等） |
| 扩展性 | 分类可扩展、字段预留，便于后续迭代 |

## 6. 业务流程

### 6.1 档案新增流程

1. 用户登录系统。
2. 进入「档案管理」，点击「新增档案」。
3. 填写档案字段（名称、分类、颁发机构、日期、有效期等）。
4. 可选上传附件扫描件。
5. 提交保存，生成档案记录，写入操作日志。

### 6.2 到期提醒流程

1. 系统定时（或实时）扫描填写了「有效期至」的档案。
2. 按规则判定为「即将到期」或「已过期」。
3. 用户登录后，首页展示提醒列表与数量。

### 6.3 导入流程

1. 下载导入模板。
2. 按模板填写档案信息。
3. 上传 Excel，系统校验格式。
4. 校验通过则批量入库，失败则返回错误行提示。

## 7. 范围界定

### 7.1 本期范围（MVP）

- 档案 CRUD + 完整元数据字段
- 附件上传/预览/下载（本地存储）
- 三大默认分类 + 自定义分类
- 搜索、筛选、首页统计概览
- 站内到期提醒
- Excel 导入/导出
- 操作日志
- 用户与管理员账号体系（个人私有权限模型）

### 7.2 后续迭代（不在本期）

- 邮件/短信到期提醒
- 对象存储（MinIO/OSS）接入
- 部门/分组隔离与共享
- 移动端适配 / 移动 App
- 数据报表与可视化大屏
