## 附：业务逻辑重构说明（2026-08-21）

系统定位调整为：每个用户只能看到并管理自己的档案（隐私隔离），由用户自行注册账号，不再需要管理员。

### 变更内容

1. **去掉管理员角色**：`users` 表废弃 `role` 字段；删除 `get_current_admin` 依赖、用户管理接口（`/api/users`）、前端「用户管理」页。
2. **开放注册**：新增 `POST /api/auth/register`（用户名+密码+可选姓名），注册成功即返回 token 并自动登录；注册时自动为该用户创建默认三大分类（证件类/获奖证书类/经历证明类）。登录页新增「立即注册」切换。
3. **分类私有化**：`categories` 表新增 `user_id` 字段；分类接口全部按当前用户隔离（列表/增删改均限本人）；`init_db` 不再预置全局分类与管理员。
4. **移除操作日志**：删除 `operation_logs` 表、`log_service`、`/api/logs` 接口、前端「操作日志」页及相关 schema。
5. **其他清理**：`config.py` 移除 `ADMIN_USERNAME/ADMIN_PASSWORD`；`init_db.py` 简化为「建库 + 建表」两步（注册时按用户初始化分类）；`status` 字段保留但无停用入口（默认恒启用）。

### 变更后的接口清单（17 个）

- 认证：`POST /api/auth/register`、`POST /api/auth/login`、`GET /api/auth/me`
- 档案：列表/新增/详情/编辑/删除 + `expiring`/`expired`/`export`/`import`/`import/template`
- 附件：上传 `POST /api/archives/{id}/attachments`、下载 `GET /api/attachments/{id}/download`、删除 `DELETE /api/attachments/{id}`
- 分类：`GET/POST /api/categories`、`PUT/DELETE /api/categories/{id}`（本人私有）
- 统计：`GET /api/dashboard/stats`
- 健康检查：`GET /api/health`

## 三、关键约定与实现细节

1. **认证**：JWT Bearer token；登录返回 `{ access_token, token_type, user }`。
2. **数据隔离**：普通用户仅 `user_id = 当前用户`；管理员可传 `user_id` 过滤查看任意用户。
3. **软删除**：档案 `deleted_at` 标记，列表默认过滤。
4. **附件**：本地 `storage/{user_id}/{archive_id}/{uuid}.{ext}`；限 20MB、jpg/jpeg/png/pdf；下载/删除校验权限。
5. **到期提醒**：`EXPIRE_REMIND_DAYS`（默认 30 天）实时计算，无需持久化。
6. **默认管理员**：`admin` / `admin123`。
7. **数据库名**：`e_archives_system`。
8. **默认分类**：证件类、获奖证书类、经历证明类。

### 技术取舍

| 项 | 结论 |
|----|------|
| SQLAlchemy 同步 vs 异步 | **采用同步**（`session.py` 同步实现，简单够用） |
| 数据库建表 | 当前 `Base.metadata.create_all` 兜底，未引入 Alembic |
| 数据库初始化 | `init_db.py` 升级为**交互式初始化模块**：自动建库 + 建表 + 初始化默认数据，支持写入 `.env` |
| 密码哈希 | 直接使用 `bcrypt` 库（**移除 `passlib`**，因 passlib 1.7.4 与 bcrypt 4.x+ 不兼容导致哈希崩溃） |
| 操作日志 | 在 service 层显式调用 `log_action` 记录 create/update/delete/import/export |
| 到期提醒 | 首页/列表实时计算；未引入 APScheduler 定时任务（站内提醒足够） |

## 五、启动指引

1. 后端：
   ```bash
   cd backend
   python -m venv venv && venv\Scripts\activate   # Windows
   pip install -r requirements.txt
   python -m app.db.init_db                        # 交互式初始化：输入 MySQL 用户名密码，自动建库/建表/建管理员
   uvicorn app.main:app --reload
   ```
   > 首次部署无需手动建库。`init_db` 会交互式询问 MySQL 连接信息（主机/端口/用户名/密码/库名）与管理员账号密码，自动创建数据库与全部数据表，并可选将连接信息写入 `backend/.env`。
2. 前端：
   ```bash
   cd frontend && npm install && npm run dev
   ```
3. 访问 `http://localhost:5173`，用 `admin/admin123` 登录。
